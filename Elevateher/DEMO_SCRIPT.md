# ElevateHer Demo Script

## 90-Second Pitch (1 slide)

1. **Hook (10s)**: "4 out of 5 potential role models are invisible to girls in SE Asia"
2. **Problem (20s)**: Career mentorship requires smartphone/internet - but 2.4B underserved women
3. **Solution (30s)**: AI-powered mentorship via SMS/USSD - works offline on basic phones
4. **Tech (20s)**: SEA-LION-E5 embeddings + temporal grooming detection + Phi-3 agent
5. **Impact (10s)**: SDG 4.4, 5.5, 8.6 aligned - pilot with INTI, NYP

## 3-Minute Interactive Demo

### Setup (before demo)
- Docker stack running with seed data (3 mentor/3 mentee profiles)
- Models in mock mode (deterministic fallback works)

### Flow (live demo)

| Time | Action | What to say | Graceful if fails |
|------|--------|-------------|-----------------|
| 0:00 | `curl localhost:8000/health` | "API is healthy - database, Redis, safety layer all running" | Skip - show mock response |
| 0:30 | Show web app at localhost:3000 | "Mentee onboarding - 5 languages supported" | Show static screens |
| 1:00 | Register new mentee | "No app download needed - works on any phone" | Pre-filled form |
| 1:30 | Show matching logic | "SEA-LION finds the best mentor for this track" | Mock match shown |
| 2:00 | Dashboard at localhost:3001 | "B2B partners see real-time impact" | Show static dashboard |
| 2:30 | Safety layer | "Every bio scanned before approval" | Show safety scores |
| 3:00 | Wrap | "Ready for pilot with NYP/INTI" |

## Graceful Degradation Table

| Component | If fails | Fallback |
|-----------|----------|----------|
| Docker | Demo on laptop only | Run Python API directly |
| Models | No AI | Deterministic matching works |
| Database | No PostgreSQL | SQLite mode (demo only) |
| Redis | No Redis | In-memory mock |
| SMS/USSD | No gateway | Simulator at localhost:3000/ussd-simulator |

## Demo Data Requirements (Generated by seed_demo_data.py)

- **Mentors**: 3 diverse profiles (STEM, Business, Trades)
- **Mentees**: 3 diverse profiles from Southeast Asia
- **Matches**: 3 active matching sessions with conversation history
- **Institution**: Pre-populated for "INTI University" (`inti-university-malaysia`)

## Key Talking Points

- "Works on a $20 Nokia feature phone"
- "SEA-LION trained on Manglish/Singlish"
- "Guardian consent for users under 18"
- "Real-time safety scanning"
